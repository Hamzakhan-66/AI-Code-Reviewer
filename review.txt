Bug:
The function `read_file` does not handle the case when the file is not a text file. If the file is a binary file, it will cause an error when trying to read it with `encoding="utf-8"`.

Fix:
Add a check to see if the file is a text file before trying to read it.

Corrected Code:
```python
def read_file(path):
    try:
        with open(path, "r", encoding="utf-8") as f:
            data = f.read()
        return data
    except FileNotFoundError:
        return "File not found"
    except Exception as e:
        return f"Error: {e}"
    except UnicodeDecodeError:
        return "File is not a text file"
```
